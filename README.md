# 運彩分析機器人（足球 + NBA → Telegram）

用約兩年的歷史賠率回測「盤口變化、各家賠率差、球員休息/傷兵」等規律，
只把**通過統計檢驗**的規律拿來即時監控，有訊號就推播到 Telegram，並自動追蹤實戰成績。

> ⚠️ 研究用途，不構成投注建議。博彩長期平均是負報酬（莊家抽水足球約 6%、NBA 約 4.4%），
> 回測有效不代表未來有效。請只用輸得起的錢。

## 資料來源（全部免費）

| 用途 | 來源 | 內容 |
|---|---|---|
| 足球歷史 | football-data.co.uk | 11 個聯賽 2024-25、2025-26、2026-27 已完賽，約 8,300 場；多家博彩公司 + Betfair 交易所的開盤/收盤賠率、亞洲讓球、大小球 |
| NBA 歷史 | ESPN | 2024-25、2025-26 例行賽 + 季後賽 2,638 場；ESPN BET / DraftKings 開盤與收盤的讓分、大小分、不讓分 |
| 即時盤口 | ESPN scoreboard | NBA + 11 個足球聯賽 + 歐冠/歐霸，DraftKings 開盤與即時盤口 |
| NBA 傷兵 | ESPN injuries | 主力（場均 ≥15 分）狀態變成 Out / Doubtful 或傷癒回歸 |
| 多家比價（選用） | The Odds API | 填 `ODDS_API_KEY` 後，每天 2 次比較各家賠率與 Pinnacle/Betfair 公平價 |

## 回測結果摘要（2026-10-14）

完整表格在 `data/backtest_report.md`。

- **NBA 不讓分盤口變動 ≥5pp → 跟進資金方向**：583 注、命中 59.5%、ROI +7.3%、p=0.045，兩季都正 → **⭐ 啟用**
  - 兩家博彩公司分別 +7.2% / +7.4%，17 個月中 11 個月賺錢；但拿掉最賺的 10 注後只剩 +0.8%，證據偏弱
- **[交叉] NBA 讓分盤移動 ≥2 分、但大小分幾乎沒動 → 跟進讓分**：309 注、贏盤 57%、ROI +9.2%、p=0.045，兩季都正 → **⭐ 啟用**
  - 比上一個穩：拿掉最賺的 10 注仍有 +6.1%，兩家博彩公司都正；大小分同時變動時就沒效（-2.6% / +0.2%）
- NBA 讓分盤移動 ≥3~4 分跟進：+3.3% ~ +6.5%，方向一致但未達顯著 → 參考
- [交叉] 足球讓球 ≥1 球但預期低進球（大2.5 <50%）→ 買受讓方 +5.2%（197 注，不顯著）；同條件買讓球方 -11.4%
- 所有「反向」（賭市場反應過度）策略都是負報酬：**盤口往哪邊移，通常是對的**
- 足球：盤口變化、亞洲讓球移動、尖銳盤 vs 平均盤都**沒有找到穩定優勢**；早盤比價（最高賠率比 Betfair 公平價高 5% 以上）+5% 但不顯著
- MLB（7,409 場、含 118 場季後賽）：盤口變化、讓分×大小交叉都**沒有**找到優勢；季後賽盲買熱門 +3.0%、盲買主隊 -6.0%（樣本小）
- 盲目下注基準：足球主勝 -8.6%、客勝 -11.2%；NBA 主隊讓分 -2.9%

## 你會收到的 Telegram 訊息

| 訊息 | 時機 |
|---|---|
| ⭐ 下注訊號 | 開賽前 3 小時（NBA）/ 4 小時（足球）內，啟用的策略成立 |
| 👀 盤口異動預警 | 更早就已經成立，先提醒觀察（回測是用收盤價，所以還不是下注時機） |
| 🚑 NBA 主力傷兵異動 | 該隊 36 小時內有比賽，附上盤口有沒有反應 |
| 💰 各家賠率比價 | 有設定 The Odds API 時 |
| 🧾 賽後檢討 | 每天 10:00（前 18 小時有完賽比賽才發；config.DAILY_REVIEW_HOUR 可關） |
| 📅 每日賽事總覽 | 每天 12:00 |
| 📊 每週實戰成績 | 每週一 12:05（含 CLV） |

每則訊號都會附「**運彩賠率 ≥ X 才有正期望值**」：把回測中「實際勝率比市場機率高多少」加回目前的市場機率換算而來。
運彩開出的賠率低於 X 就不值得下（運彩抽水通常比國外博彩公司重）。

## 在 Telegram 直接問機器人

| 輸入 | 回覆 |
|---|---|
| 隊名：`曼城`、`皇馬`、`Arsenal`、`湖人`、`LAL` | 該隊下一場比賽的完整分析 |
| 聯賽：`歐冠`、`歐霸`、`英超`、`西甲`… | 未來 36 小時整個聯賽的總表 + 每場分析 |
| `/nba` | NBA 未來 24 小時 |
| `MLB`、`棒球`、`季後賽` | MLB 未來 48 小時：先發投手（ERA/WHIP/K9）、系列賽、短期傷兵、ESPN 模型、歷史相似盤口、運彩其他大小分的合理賠率 |
| `/today`、`/report`、`/help` | 每日總覽、實戰成績、說明 |
| `串關`（可加聯賽：`串關 英超`、`串關 全部`） | 二串一、三串一各 3 張：期望值最高 / 命中率最高 / 平衡，附「運彩組合賠率至少要多少」 |
| `賽後`（或 `/review`） | 過去 24 小時完賽比賽：賽前預測 vs 實際、爆冷、資金方向準不準、模型 vs 市場 |

單場分析內容：近 5 場、積分、DK 開盤→現在的勝平負/讓球/大小（去水機率）、盤口變化對照回測、
**歷史相似盤口**（勝平負機率 + 大2.5 機率都接近的 2024–26 比賽 → 讓分 × 大小交叉的實際賽果）、
各選項的**合理賠率**與期望值。3.5 / 1.5 球的盤口用 Poisson 換算成大 2.5 機率，才能跟歷史資料比。

## 每天自動做的事（電腦睡著錯過時間，醒來會補跑）

| 時間 | 內容 |
|---|---|
| 每 30 分鐘 | 抓盤口快照；開賽前 3 小時內記錄每個選項的模型預測；完賽自動結算預測與串關 |
| 10:00 | 🧾 盤後分析：足球 + MLB/NBA 賽果對照、串關結果與累計戰績、模型學習狀態與校準表 |
| 12:00 | 📅 每日賽事總覽 |
| 12:30 | 🎟️ 每日串關（未來 24 小時，足球 + MLB + NBA；同一關最多 2 張、同一場最多 2 張），存檔供隔天結算 |
| 週一 | 📊 每週成績 + 重新下載資料並回測 |

**模型怎麼學**（learning.py）：估計勝率 = 市場機率與「歷史相似盤口」加權。每天用已結算的預測，
試不同權重找 log loss 最低的，往那邊調一半（足球、MLB、NBA 各自一個）；滿 120 場才開始調整。

## 常用指令

```bash
.venv\Scripts\python main.py backtest --send    # 重新回測並把報告發到 Telegram
.venv\Scripts\python main.py run --dry-run      # 跑一輪監控，只印出不發送（用暫存資料庫，不影響正式紀錄）
.venv\Scripts\python main.py digest             # 立即發每日總覽
.venv\Scripts\python main.py report             # 立即發實戰成績
.venv\Scripts\python main.py strategies         # 列出啟用 / 參考策略
.venv\Scripts\python main.py league 歐冠          # 歐冠分析發到 Telegram
.venv\Scripts\python main.py analyze 曼城         # 單隊分析發到 Telegram
.venv\Scripts\python main.py test-notify        # Telegram 測試
```

背景執行：Windows 工作排程器 **SportsBetting**（登入後 1 分鐘啟動 `main.py loop`）：每 30 分鐘監控、每週一 06:00 自動更新資料並重新回測。

```powershell
Stop-ScheduledTask SportsBetting; Start-ScheduledTask SportsBetting   # 改完程式後重啟
Disable-ScheduledTask SportsBetting                                    # 停用
```

## 可調整的地方（config.py）

- `FOOTBALL_LEAGUES` / `FOOTBALL_CUPS`：監控哪些聯賽
- `MIN_BETS`、`MAX_P_VALUE`、`REQUIRE_POSITIVE_EACH_SEASON`：策略要多嚴格才啟用
- `SIGNAL_WINDOW_HOURS`：開賽前多久發訊號
- `INJURY_KEY_PLAYER_MIN_PPG`：多少分算主力

## 已知限制

- NBA 歷史只有一家博彩公司（ESPN BET → DraftKings），且不知道 ESPN「收盤」的確切擷取時間；
  即時訊號在開賽前 3 小時發出，若之後還有大變動（例如臨時傷退）就抓不到。每週報告的 CLV 會顯示這個落差。
- 足球即時盤口只有 DraftKings，回測則是多家平均；足球「開盤」定義也不同（程式會優先用賽前 1–2 天的快照對齊）。
- 足球沒有免費的傷兵資料源；球員異動主要靠盤口變化間接反映。
- 運彩本身的歷史賠率抓不到（官網擋爬蟲），所以回測用的是國外博彩公司價格。
